# Phishing-Attack-Simulation

This project is to simulate a phishing attack in a controlled lab 
environment using Kali Linux and GoPhish with a Gmail account for sending 
emails.The purpose of the simulation is to understand how phishing attacks are 
carried out and how attackers trick users into revealing sensitive information such 
as usernames and passwords. This project also aims to demonstrate how 
phishing attacks can be detected and prevented.The experiment is conducted in 
a controlled environment for educational purposes only and does not target 
real users.
